# ApexTrack: Terminal-Based Motorsport Championship CLI

## Overview
A beginner-friendly, console-based Java application (`apextrack.cli`) for managing motorsport teams, drivers, races, championship standings, basic race simulation, MySQL JDBC persistence, Java Stream analytics, and CSV file I/O.

## Team & Class Split (33 Classes Total — 11 Per Member)

## Setup & Run
1. Install **JDK 21** and **MySQL Server**, then run `src/main/resources/schema.sql`.
2. Add `mysql-connector-j` (JDBC driver) to your project classpath/libraries.
3. Run `com.apextrack.MainApp` from VS Code or your terminal.
